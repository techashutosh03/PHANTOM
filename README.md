# PHANTOM

PHANTOM is a personal AI assistant project that I'm building to explore the future of intelligent and interactive software.

The idea started with a simple question:

> What if an AI assistant could do more than just chat?

My goal is to gradually turn PHANTOM into a smart platform that combines conversation, automation, visual understanding, and productivity tools in one place.

## Current Features

- User authentication system
- Chat interface
- Notes management
- Database integration
- Responsive web interface
- Backend server with Node.js and Express
- SQLite database support

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database

## Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/PHANTOM.git
```

Move into the project folder:

```bash
cd PHANTOM
```

Install dependencies:

```bash
npm install
```

Start the server:

```bash
node server.js
```

Open your browser and visit:

```text
http://localhost:3000
```
